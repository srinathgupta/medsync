🔧 Developer · Firebase Data Structure ▼
READ
device/status
ESP32 writes every 10 s and on every change. lastSeen is the Firebase server time (online check).
{ "state": "IDLE", "time": "14:23:05", "scheduleHour": 8, "scheduleMinute": 0, "doseCount": 2, "scheduleValid": true, "voiceMode": "both", "outboxPending": 0, "fw": "4.0.0", "lastSeen": 1761... }
WRITE
device/schedule
Web app writes; ESP32 reads it every 8 s and reports what it runs in device/status.
{ "hour": 8, "minute": 30, "doseCount": 2, "med": "Metformin", "timestamp": 1737... }
WRITE
device/prediction
TF.js logistic regression (≥20 doses) or Bayesian fallback.
{ "riskScore": 62, "riskLevel": "HIGH", "sampleSize": 24, "method": "ml", "computedAt": 1737... }
READ
device/history · device/log
History key = doseId_status, row {time, med, dose, status, timestamp (UTC s), doseId, sched}. Log: device counters.
{ "totalDispensed": 14, "totalConfirmed": 12, "totalMissed": 2 }
